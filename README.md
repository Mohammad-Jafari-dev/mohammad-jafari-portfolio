🌿 Overview

Welcome to my personal portfolio repository!

This project is designed to introduce me, showcase my technical interests and skills, and provide a place to present my future projects.

The visual identity combines a Dark Digital Forest aesthetic with modern web design, subtle animations, and a clean user experience.

«Learn deeply. Think scientifically. Build intelligently.»

✨ Features

- 🌲 Modern dark forest-inspired design
- 📱 Responsive layout for different screen sizes
- 🌍 Multilingual interface with 11 languages
- 🎨 Smooth transitions and subtle animations
- 🧭 Interactive navigation
- 💻 Technology and skills showcase
- 🚀 Dedicated projects section
- 📬 Contact and social media links
- ♿ Accessibility-conscious design

🚀 Getting Started

This is a static website. You don't need Node.js, npm, or a build system.

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

That's it!

🖥️ Architecture

This project currently uses a Frontend-only architecture.

- No backend server
- No database
- No server-side framework
- No build tools required

The website runs directly in the browser using HTML, CSS, and JavaScript.
